# Como contribuir

Obrigado por considerar contribuir com o Sistema de Gestão de Notas!

1. Faça um fork do repositório ou crie uma branch para sua alteração.
2. Mantenha o código compatível com Java 17 e com a configuração Maven do projeto.
3. Descreva claramente a alteração e, quando possível, inclua testes.
4. Execute `mvn clean verify` antes de abrir um pull request.
5. Explique no pull request o problema resolvido e como validar a mudança.

Não envie senhas, tokens, dados pessoais reais de alunos ou arquivos do banco H2.
